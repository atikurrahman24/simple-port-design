🧠 Project: Simple Portfolio Design

Live Demo: atikurrahman24.github.io/simple-port-design/

📌 Overview

This is a simple portfolio website developed using HTML5, CSS3, and Tailwind CSS. It serves as a digital resume, showcasing my skills, recent work, and contact information in a clean, modern, and responsive layout.

🛠️ Technologies Used

  - HTML5 – Structuring the content
  - CSS3 – Styling the layout
  - Tailwind CSS – Utility-first framework for modern and responsive design
  - Font Awesome – Icons for UI enhancements (if used)
  - Google Fonts – Typography

⚙️ Features

  - Responsive Design: Fully compatible across desktop, tablet, and mobile devices
  - Home Section: Introduction with a brief description
  - About Me: Background and profession
  - Skills: Highlighting my expertise and areas of proficiency
  - Recent Work: Displaying recent projects and designs
  - Contact: Easy way for visitors to reach out
  - Smooth Hover Effects: Interactive elements styled with Tailwind transitions

🧩 Challenges Faced

  - Ensuring responsive layout with Tailwind CSS utility classes
  - Properly aligning grid and flex items
  - Maintaining visual consistency and balance
  - Implementing hover and transition effects smoothly
  - Managing spacing and padding for a clean design flow

🎯 Outcome

The final website is fully responsive, visually appealing, and effectively showcases my skills and recent work. It serves as a digital portfolio for potential clients and employers.
